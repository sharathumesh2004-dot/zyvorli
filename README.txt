ZYVORLI - phone-only install guide
==================================
You do not need a laptop. Everything below is done on your phone.

PART 1 - Put the app online (once, free)
1. Unzip this file in your Files app (tap the zip, then Extract / Unzip).
2. In your phone browser, go to github.com and create a free account.
3. Tap + (top right) > New repository. Name: zyvorli. Choose Public. Create.
4. Tap "uploading an existing file" (or Add file > Upload files).
   Select ALL 9 files from the extracted folder (index.html, manifest.webmanifest,
   sw.js, README.txt and the 5 .png files). Tap Commit changes.
5. Open Settings > Pages. Under "Build and deployment" choose
   Source: Deploy from a branch, Branch: main, Folder: / (root). Tap Save.
6. Wait 1 to 2 minutes and refresh the Pages screen. It shows your app address:
   https://YOURNAME.github.io/zyvorli/

PART 2 - Install it on the phone
iPhone (Safari): open the address > Share button > Add to Home Screen > Add.
Android (Chrome): open the address > tap "Install app" on the welcome screen
                  (or the 3-dot menu > Install app).

PART 3 - Share with friends
Send the address on WhatsApp or any app. They open it and install the same way.

Note: this is the demo version. Messages are simulated on each phone and do not
reach other phones until the server is connected.
